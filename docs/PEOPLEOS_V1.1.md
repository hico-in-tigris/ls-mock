# PeopleOS v1.1 実装ドキュメント

## 概要

PeopleOS（仲間・協力者一覧）ページを刷新し、LocalSuccess のコア思想（思考フロー：気づき→仮説→検証→プロジェクト化→仲間づくり→推進）をベースに、"地域プレイヤーのレーダー" となる一覧ページを構築しました。

## データモデル拡張

既存のAPIデータ（`base44.entities.Person`）から、以下の新しいフィールドを計算・追加：

- **`status`**: 未接触 / 接触済み / 関係深化中（最終接触日から自動判定）
- **`activityScore`**: アクティブ度（1〜100）
  - 計算式: `(プロジェクト数 × 15) + (スキル数 × 5) + (関心数 × 5) + (接触日によるボーナス)`
- **`stage`**: 思考ステージ（気づき / 仮説 / 検証 / プロジェクト化 / 仲間づくり / 推進）
  - プロジェクト数とスキル数から自動推定
- **`recentActivity`**: 最近の1行アクティビティ（簡易版）
- **`fullName`**: フルネーム（既存のnameをそのまま使用）
- **`interests`**: 関心領域（既存のvaluesをマッピング）
- **`area`**: 活動エリア（今後追加予定）

## フィルタリング仕様

### キーワード検索
- `name`, `fullName`, `recentActivity`, `interests`, `skills` を部分一致検索

### タグフィルター（OR条件）
- **関心タグ**: 選択したタグのいずれかを含む人物を表示
- **スキルタグ**: 選択したタグのいずれかを含む人物を表示

### 完全一致フィルター
- **思考ステージ**: 完全一致
- **役割**: 完全一致
- **ステータス**: 完全一致

### ソート
- `activityScore`: アクティビティスコア順（デフォルト）
- `name`: 名前順
- `projectCount`: プロジェクト数順

## 設計理由

### 1. 思考フローの可視化
- **思考ステージ**を各カードに表示することで、地域プレイヤーがどの段階にいるか一目で把握
- ステージごとに色分けすることで、視覚的に理解しやすく

### 2. 地域プレイヤーのレーダー
- **アクティビティスコア**によるランキングで、積極的に活動している人を発見
- **関心タグ・スキルタグ**による柔軟な検索で、必要な人材を素早く見つけられる

### 3. 情報密度の適正化
- カード形式で一覧性を確保
- 重要な情報（関心、スキル、ステージ）を優先表示
- 詳細はクリックで確認できる設計

### 4. 即時フィルタリング
- クライアントサイドで完結するため、レスポンスが速い
- 複数のフィルターを組み合わせて柔軟に絞り込み可能
