# LocalSuccess

地域プレイヤーの思考・仮説・仲間づくり・事業推進をつなげるローカル起業OS

LocalSuccess は、地域おこし協力隊・自治体職員・地域プレイヤーのための
**「思考整理 → 仮説づくり → 小さな検証 → プロジェクト化 → 仲間づくり → 推進」**
を一気通貫で支援するクラウドサービスです。

従来の「タスク管理」や「プロジェクト管理」に留まらず、
**"地域で事業をつくる人の思考プロセスそのもの"** を支援することを目的にしています。

## 🚀 クイックスタート

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番用ビルド
npm run build
```

詳細は [開発ガイド](./docs/DEVELOPMENT.md) を参照してください。
