# LocalSuccess

地域プレイヤーの思考・仮説・仲間づくり・事業推進をつなげるローカル起業OS

LocalSuccess は、地域おこし協力隊・自治体職員・地域プレイヤーのための
**「思考整理 → 仮説づくり → 小さな検証 → プロジェクト化 → 仲間づくり → 推進」**
を一気通貫で支援するクラウドサービスです。

従来の「タスク管理」や「プロジェクト管理」に留まらず、
**"地域で事業をつくる人の思考プロセスそのもの"** を支援することを目的にしています。

---

## 🌱 Core Concept

地域プレイヤーは、日々の活動の中で「気づき」「違和感」「やりたいこと」を抱えています。
しかし多くの場合、それらはメモに埋もれ、仮説に昇華されず、行動につながらないことが課題です。

LocalSuccess はこの課題に対して**「思考の外部化」**を軸にアプローチします。

---

## 🧠 1. 仮説OS（思考整理エンジン）

### ■ 日々の感じたことから仮説をつくる

ユーザーは、ただ日々感じたこと・モヤモヤ・疑問を入力するだけ。
AI が 3〜5 個の "仮説パターン" を生成し、ユーザーがしっくりくるものを選びます。

#### 仮説カードに含まれる要素

- 仮説タイトル
- 対象（誰の課題か）
- 背景（地域文脈）
- 検証の切り口

### ■ AI は「答え」ではなく「問い」を返す

「じゃあどうしたらいい？」と問いかけると、
AI は"行動案"ではなく **思考を深めるための問い** を返します。

**例：**
- 対象者の行動パターンはどんな流れ？
- この仮説が正しいとしたら、どんな感情が背景？
- 最短で検証できる相手は？

この仕組みによって、ユーザーは **自走的に小さな一歩を発見** していきます。

### ■ 検証ログと事業化

小さな検証ログを積み重ねていくことで、
自然と「事業として成立する構造」が見えてきます。

---

## 👥 2. PeopleOS（地域人材データベース）

LocalSuccess には、地域関係者のデータベースが搭載されています。

### ■ 登録される人物像

行政 / 協力隊 / 住民 / NPO / 専門家 / 事業者 など、
地域で動くあらゆるプレイヤーを対象とします。

#### スキルセット例

- ファシリテーション
- 企画 / イベント運営
- 事業戦略
- 農業・林業スキル
- デザイン / PR
- 協力隊OBOG ならではの暗黙知

#### 想い・価値観

- 地域で何を良くしたいと思っているか
- どんなテーマに心が動くか
- 個人ミッション
- 関わりしろ

これらのデータは AI によって構造化され、
**価値観・スキルの両面からのマッチング** を可能にします。

---

## 🔗 3. 仮説OS × PeopleOS の連動

このプロダクトの真価は「思考」と「人」が接続される瞬間です。

### 仮説を立てたとき、AI が People DB の中から

- 同じ価値観を持つ人
- この領域に強い関心がある人
- スキルがフィットする人
- 過去に似たプロジェクトに関わった人

を推薦してくれます。

これにより、
**想いベースの協働が自然に生まれる土壌** ができます。

---

## 🚀 4. プロジェクト化と推進

仮説 → 小さな検証 → 仲間集め → プロジェクト化
という流れは、協力隊の任期（1〜3年）と極めて相性が良い。

LocalSuccess では以下ができます：

- 検証ログから自動でプロジェクトの骨格を生成
- 必要な仲間を People OS から推薦
- プロジェクトの目的・文脈がすでに整理されている
- 町のミッションや施策にも紐づけやすい

これにより、
**「思いつきを地域の未来につながる事業まで持っていく」一連の流れをサポート** します。

## 🗂 主要機能一覧

### ダッシュボード

今日のやること・検証中の仮説・進行中のプロジェクト・要フォロー関係者を表示。

### Thought Entry（思考の投げ込み）

感じたことを入力すると仮説生成がスタート。

### 仮説カード

思考の母艦。問い返し → 行動メモ → 検証ログが蓄積。

### People データベース

地域プレイヤーのスキル・想い・接触履歴を可視化。マッチングの基盤。

### Actions

小さな行動ログ。タスクではなく"検証行動"として扱う。

### Summary

仮説 → 検証 → 結果 というストーリーをまとめ、成果報告やふりかえりに活用。

### Projects

5段階のウィザード形式でプロジェクトを設計・管理
- アイデア整理
- 企画構成（5W1H）
- 目標設定（SMART目標・KPI）
- 関係者分析
- 提案作成

### Settings

アプリケーション設定

## 🛠️ 技術スタック

- **フレームワーク**: React 18 + Vite 6

  - date-fns（日付処理）

## 🔧 設定

### MockDB（擬似データベース）

このアプリケーションは、Base44 SDKの代わりに**MockDB**というlocalStorageベースの擬似データベースを使用しています。

- **データ保存**: ブラウザのlocalStorageに保存されます
- **データ永続化**: ブラウザを閉じてもデータは保持されます
- **初期データ**: アプリ起動時にサンプルデータが自動的にシードされます

#### データのクリア

開発中にデータをリセットしたい場合は、ブラウザの開発者ツールで以下を実行：

```javascript
// すべてのMockDBデータをクリア
localStorage.clear();
```

または、特定のエンティティのみクリア：

```javascript
// Personデータのみクリア
localStorage.removeItem('mockdb_Person');
```

## 🎯 Why LocalSuccess?

地域づくりは「情報」ではなく「思考」から始まる。
そして人が動くのは「正しく整理された仮説」と「共感する仲間」が揃ったとき。

LocalSuccess はその両方を支える OS として、
協力隊・自治体・地域プレイヤーの可能性を最大化します。
